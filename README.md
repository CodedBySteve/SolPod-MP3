# SolPod-MP3
A starter project for the development of an MP3 device with additional features usually found in dj decks, with distinctive physical designs in plan comparing different from the market. This means the device will not only play music but let you modify it and mix it to make your own "dj" performance, allowing you to modify music that is expressed into your likings..

## Features:
* MP3 player basic features:
  * Play
  * Pause
  * Next
  * Previous
  * playlists
  * imports
  * downloads
  * etc...
* dj deck essential features: (researching and exploring this topic...)
